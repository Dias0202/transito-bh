# Trânsito BH

**https://dias0202.github.io/transito-bh/**

**PT** · Um estudo independente com dados abertos sobre onde, quando e com quem o trânsito de Belo Horizonte fere —
e o que dados e aprendizado de máquina dizem sobre o que funciona. Sinistros com vítima de 2011 a 2026, chuva,
feriados, radares e redutores de velocidade.

**EN** · An independent open-data study of where, when and whom Belo Horizonte's traffic hurts — and what data and
machine learning say about what works. Injury crashes 2011–2026, rain, holidays, speed cameras and speed bumps.

Este repositório contém apenas o site publicado (arquivos estáticos e agregados). · This repository holds only the
published site (static files and aggregates).
